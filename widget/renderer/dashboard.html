ONE AI REPLY = ONE SIP = 3.5 mL

Claude Code replies count once per message ID, including streamed chunks and subagents. Codex counts new token-usage events, with repeated totals removed. A sent web prompt counts as one prompt and one sip.

Human prompts and available input, cache and output tokens are shown separately. Tokens are never converted to water.

COUNTS ONLY. NOTHING LEAVES THE MACHINE.

Logs are opened read-only. Only counts, IDs, hashed dedupe keys and byte offsets are saved locally. The extension sends counts to 127.0.0.1, never prompt text.

Plain chats inside the Claude and ChatGPT desktop apps have no local log and cannot be tracked. Their Code and Codex sessions are tracked.
